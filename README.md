# أساسيات ميكانيكا الموائع — منصة تدريب تفاعلية

موقع تعليمي مُلعّب (Gamified) لمقرر **أساسيات ميكانيكا الموائع** بالكلية التقنية،
موجّه لمتدربي **الصيانة الميكانيكية** (مضخات، ضواغط، مراوح، توربينات).

## المزايا
- 📱 مصمم للجوال أولًا، ويعمل **دون اتصال** بعد أول زيارة (PWA قابل للتثبيت).
- 🧭 **اختبار تشخيصي** يرسم خطة شخصية لكل متدرب، واختبارات قبلية ترتّب دروس كل وحدة حسب حاجته.
- 🎮 تلعيب كامل: نقاط خبرة XP، مستويات ورُتب، أوسمة، وأيام مواظبة.
- 🔬 **14 محاكاة فيزيائية تفاعلية** بمهام استكشاف: من سباق اللزوجة إلى منظومة الضخ والتكهف.
- 🃏 أنشطة تفاعلية داخل كل درس: بطاقات قلب، توصيل، ترتيب خطوات.
- 📖 مسرد مصطلحات عربي–إنجليزي قابل للبحث.
- 🔒 كل التقدم يُخزَّن محليًا على جهاز المتدرب فقط (localStorage) — لا خوادم ولا حسابات.

## التقنية
HTML + CSS + JavaScript (ES Modules) خالص — بدون أي مكتبات أو أدوات بناء.
المحاكاة عبر Canvas 2D. الخط Cairo مضمّن محليًا.

## التشغيل محليًا
```bash
# أي خادم ملفات ثابت يكفي:
python -m http.server 8000
# ثم افتح http://localhost:8000
```

## البنية
```
data/       محتوى المقرر وبنوك الأسئلة والمسرد
js/screens/ شاشات التطبيق
js/sims/    وحدات المحاكاة
css/        نظام التصميم
```

لتعديل المحتوى: حرّر `data/unit1.js` … `data/unit4.js` (بنية البطاقات موثقة في `DESIGN.md`).
عند إضافة ملفات جديدة حدّث قائمة `ASSETS` في `sw.js` وارفع رقم `CACHE_VERSION`.
